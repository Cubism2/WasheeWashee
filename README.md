# Mr. Washee Washee overlay

This is just a silly joke mod that overlays Mr. Washee Washee from Family Guy over the screen. It also lets you add Moe from the Simpsons over the screen too

## Features

* **Enable** or **disable** Mr. Washee Washee and Moe in the mod options
* **Randomize** the **location, rotation, scale, and opacity** of either character on screen
